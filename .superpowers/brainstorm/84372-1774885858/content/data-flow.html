Key Design Decisions

✓ Marking processed elements

Each fixed element gets data-bidix="fixed" attribute. Prevents re-processing and allows easy cleanup when toggled off.

✓ Inline styles, not classes

Using element.style.direction avoids CSS specificity battles with site stylesheets. Easy to apply and remove.

✓ Skip list

Skip: <code>, <pre>, <kbd>, <script>, <style>, elements with explicit dir, nav/button elements.

✓ Event delegation for inputs

Single input event listener on document using delegation. No per-element listeners needed.
