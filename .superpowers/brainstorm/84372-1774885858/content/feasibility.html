Honest difficulty assessment for each approach

PDF ↔ DOCX Conversion + RTL Fix

🔴 Extremely Difficult

This is what companies like Adobe, Smallpdf, and iLovePDF have entire engineering teams building. Here's why:

PDF → DOCX

  • PDF is a visual format — text is placed by X/Y coordinates, not flow
  • No concept of "paragraphs" or "columns" — just painted characters
  • Fonts may be embedded/subsetted and not available in DOCX
  • Tables, lists, headers — all lost in PDF, must be reverse-engineered
  • Would need massive libraries or external API calls

Style Preservation

  • PDF styles ≠ DOCX styles (fundamentally different models)
  • Complex layouts (multi-column CVs) break during conversion
  • Even Google Docs and LibreOffice mess this up regularly
  • Doing this in a Chrome extension? Not realistic.

Verdict: This is a multi-year, multi-engineer product. Not a side project or extension.

What IS Feasible (and still solves your problem)

🟢 Option A: Smart Web RTL Fixer + PDF from Fixed DOM Our Hybrid Plan

Fix bidi on the web page → generate clean PDF from the fixed page. This works for LinkedIn CVs because we fix the DOM THEN export it.

✓ 2-3 weeks to build ✓ All client-side ✓ No external APIs
🟡 Option B: DOCX RTL Fixer (no PDF conversion)

If the user already HAS a DOCX file, fix the RTL direction inside it. DOCX is XML-based, so we CAN manipulate direction properties programmatically. Skip PDF entirely.

Workflow: Upload DOCX → fix all text direction to RTL → fix alignment → download fixed DOCX

✓ Moderate difficulty ✓ docx.js library exists ⚠ Only works if user has DOCX source
🟡 Option C: Both A + B

Chrome extension for web RTL + PDF export from DOM. Plus a simple DOCX RTL fixer tool (could be a tab in the popup or a small web app). Covers both workflows.

⚠ Larger scope but all feasible ✓ MVP the extension first, add DOCX later

Your CV Workflow: What Actually Works

English CV → Hebrew CV (keeping style):

The honest answer: you need to edit it in a tool that understands document structure (Word, Google Docs, Canva, Overleaf). No extension can reliably convert an English PDF layout to Hebrew while keeping styling. BUT — Bidix can ensure that once you build your Hebrew CV on a web platform (LinkedIn, etc.), the web view AND the exported PDF both render correctly.
